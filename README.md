# LUMAROZ WEB — MARK I

The first experimental flagship web experience for LUMAROZ INDUSTRIES PVT. LTD.

## Run locally

No build step is required.

```bash
python -m http.server 4173
```

Open http://localhost:4173

## Direction

MARK I is a motion-first, typography-led landing experience exploring Lumaroz as an independent technology system spanning intelligence, software, and physical technology.
