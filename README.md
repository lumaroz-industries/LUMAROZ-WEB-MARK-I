# LUMAROZ INDUSTRIES — MARK I

The public website for **LUMAROZ INDUSTRIES PVT. LTD.**

## Public architecture

- `/` — company home
- `/intelligence` — Lumaroz Intelligence
- `/store` — Lumaroz Store
- `/about` — company
- `/contact` — contact

**REN / JARVIS are personal projects and are intentionally not presented as public Lumaroz products or divisions.**

## Stack

- Vite
- React
- React Router
- Three.js
- CSS-first motion and responsive layout
- Lightweight single shared WebGL scene for performance

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:4173.

## Production build

```bash
npm run build
npm run preview
```

## Creative direction

The experience takes inspiration from the principles visible in high-end interactive studios such as Lusion: strong art direction, motion-led storytelling, realtime 3D, experimental presentation and technical restraint. The design and implementation are original to Lumaroz.

Reference inspiration: https://lusion.co/projects

## Company structure

### Lumaroz Intelligence
AI products, software, intelligent interfaces and future-facing digital systems.

### Lumaroz Store
Keyboards, mice, speakers and other technology / desk accessories.

The website should communicate **Lumaroz Industries first**. Individual products and future projects live underneath that company system.
